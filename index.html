How to test

Seven steps, about five minutes.

  1. Open in Chrome or Edge on a laptop or Android phone, or in Safari on an iPhone or iPad (with Dictation turned on).
  2. Allow the microphone; an earpiece or headset works best.
  3. Present → Start Listening → read the sample script aloud.
  4. Try “jump to slide three” or “go back one”.
  5. Highlight your own phrases in Script and test.
  6. No mic? Use Simulate speech. Triggers fire in script order; switch to Any order to test them individually.
  7. Send feedback to Aaron.

    Mic help

    Mic help: allow the microphone

    If the microphone is blocked, follow these steps, then tap Try again.

    Android · Chrome

    1. Tap the icon left of the address bar → Permissions → Microphone → Allow.
    2. If Chrome itself lacks mic access: Android Settings → Apps → Chrome → Permissions → Microphone → Allow.
    Open Chrome app settings (may not open on every phone)

    iPhone / iPad · Safari

    1. Use Safari. Chrome and other browsers on iPhone can't do voice recognition.
    2. Turn on Dictation: Settings → General → Keyboard → Enable Dictation.
    3. Settings → Apps → Safari → Microphone → Allow (older iOS: Settings → Safari → Microphone).
    4. Or tap “aA” in the address bar → Website Settings → Microphone → Allow.
    5. Screen Time can also block it: Settings → Screen Time → Content & Privacy Restrictions → Allowed Apps → Siri & Dictation on.

    Desktop · Chrome

    1. Click the icon left of the address bar → Site settings → Microphone → Allow, then reload.
    2. Or paste this into the address bar (pages can't open it directly): chrome://settings/content/microphone

    Mac: also open System Settings → Privacy & Security → Microphone → enable your browser.

    Windows: also open Settings → Privacy & security → Microphone → allow desktop apps.

    Live transcript

    Listens only on the presenter's own device. A close-talk earpiece or headset ignores room voices best. Voice-ID lock planned for v2.

    Voice settings

    Higher ignores more room noise. 0 sends all audio.

    Processed by Grok, not stored by SpeakEasy

    While listening, microphone audio streams through your proxy to xAI's Grok speech-to-text for live transcription. Neither SpeakEasy nor the proxy stores it. xAI doesn't train on API data; by default it keeps API requests encrypted for up to 30 days for abuse review (none if the key's team enables Zero Data Retention). Silence below the gate isn't sent, and SpeakEasy keeps only the last few seconds of text, in memory.

    Browser recognition is free. Your browser may send audio to its own speech service (Google in Chrome, Apple in Safari).

    Changes apply the next time you start listening. If Grok STT disconnects, SpeakEasy switches to Browser recognition, then to manual control.
